# EnergyMixReceipt

Batch B2. A reusable GenLayer intelligent contract that converts a public list of generation-source descriptions into a fixed source-category vector, then computes a renewable-energy share. The owner records one to eight descriptions with positive MWh amounts. Independent validators classify each description as solar, wind, hydro, nuclear, fossil, or other; deterministic code calculates the totals and basis-point share.

Descriptions and MWh values are user declarations. The receipt does not authenticate a supplier, meter, or environmental claim. A category of `OTHER` does not count as renewable. Consumers must use their own source authentication for real-world claims.

## Interface

`record_mix(mix_key, period, descriptions, amounts_mwh)` freezes an owner-scoped mix. Only that owner may call `classify_mix(mix_id)`. `get_mix(mix_id)` returns canonical JSON with every category and amount; `get_mix_count()` returns the number of mixes.

## Review boundary

The model maps descriptions to a same-length category vector. Validators independently rerun and compare that vector, including order. Amounts and share are never generated by the model. Length and amount bounds, owner authorization, one-time classification, and immutable input rows protect the accounting step.
